# План: APK для J.A.R.V.I.S.

## Подход

Собрать APK из уже готового веб-приложения через **Capacitor 8** (в репозитории есть `src/` → `dist/`).
Это самодостаточный APK, не требует хостинга и `assetlinks.json` (в отличие от TWA).

Важно: `SpeechRecognition` (Web Speech API) **не работает в Android WebView**, поэтому голос
переводим на нативные плагины:

- `@capacitor-community/speech-recognition` — Android `SpeechRecognizer` (ru-RU);
- `@capacitor-community/text-to-speech` — нативный TTS;
- `@capacitor/browser` — открытие YouTube/Google/поиска в системном браузере.

В браузере всё остаётся как сейчас (Web Speech API), выбор — по `Capacitor.isNativePlatform()`.

## Файлы

| Файл | Изменение |
| --- | --- |
| `package.json` | deps: `@capacitor/core`, `/cli`, `/android`, speech-recognition, text-to-speech, browser; scripts `android:sync`, `android:apk` |
| `capacitor.config.json` | `appId: com.aidar145.jarvis`, `appName: J.A.R.V.I.S.`, `webDir: dist`, тёмный фон |
| `android/` | сгенерировать `npx cap add android`, закоммитить; в `AndroidManifest.xml` — `RECORD_AUDIO`, `INTERNET`, `<queries>` для `RecognitionService` |
| `src/app.js` | `nativeBridge`: проверка прав микрофона, `start/stop` распознавания, `speak`, `openExternal`; веб-фолбэк без изменений |
| `scripts/make-icons.mjs` | генерация PNG-иконок из мотива `favicon.svg` (192/512 + mipmap-*), без внешних зависимостей |
| `.github/workflows/android.yml` | JDK 21 + Android SDK, `npm ci`, build, `cap sync`, `gradlew assembleDebug`, artifact `jarvis-debug.apk` |
| `.gitignore` | `android/.gradle/`, `android/**/build/`, `*.keystore`, `keystore.properties` |
| `README.md` | установка APK и сборка |

## Сборка и проверка

```bash
export JAVA_HOME=/usr/lib/jvm/temurin-21-jdk-amd64
export ANDROID_HOME=/usr/local/lib/android/sdk
npm install
npm run build
npx cap sync android
cd android && ./gradlew assembleDebug
```

- APK: `android/app/build/outputs/apk/debug/app-debug.apk` (debug-подпись, ставится через
  «Неизвестные источники»).
- Проверка: `aapt dump badging` (package, label, RECORD_AUDIO/INTERNET), `unzip -l` (assets
  `public/index.html`, `app.js` внутри APK), размер APK.
- CI: workflow отдаёт APK артефактом; для Play Store позже — release keystore через secrets.
- Эмулятора/устройства в этом окружении нет, поэтому запуск на Android проверяется только
  установкой APK пользователем.

## Ограничения

- Голосовое распознавание на Android зависит от сервиса распознавания речи (обычно Google);
  без него остаётся текстовый ввод.
- Микрофон запрашивается при первом нажатии; при отказе — текстовый режим.
- iOS не входит в задачу.
